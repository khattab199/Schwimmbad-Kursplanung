# Schwimmbad – Kursplanung

**Projektarbeit für Programmierung und Softwaretechnik**

**Autor:** Khaled Khattab	

## Projektbeschreibung

Dieses Projekt ist ein Verwaltungssystem für ein Schwimmbad.

Das System ermöglicht die Planung und Verwaltung von Schwimmkursen, die Anmeldung von Teilnehmern und die Zuweisung von Kursleitern.

## Technologien

- C#
- Visual Studio
- Microsoft SQL Server
- Git und GitHub

## Projektziel

Entwicklung einer grafischen Anwendung zur Verwaltung und Planung von Schwimmkursen.
